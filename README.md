# Calculadora de Ajuste de Ventilação Mecânica

Site estático para apoio assistencial em ventilação mecânica VCV/PCV e análise de gasometria.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os arquivos deste pacote para a raiz do repositório.
3. Em **Settings > Pages**, selecione **Deploy from a branch**.
4. Escolha a branch **main** e a pasta **/(root)**.
5. Salve e aguarde a publicação.

## Arquivo principal
`index.html`
